Setting up an STS3215 servo

I'm building a WAVEGO PRO quadruped. It uses twelve serial bus servos, so I set up one joint properly before wiring the rest. These are my notes.

01The setup

Four things on the bench:

  • One STS3215 servo, powered at 12 V.
  • A Waveshare bus servo adapter ↗, which supplies the servo and handles the bus.
  • The board's mode switch set to B, so it is driven over USB rather than from a microcontroller.
  • USB-C to my PC. It came up as /dev/ttyACM0.

From there it is Python over a serial port, using Waveshare's SDK.

02One bus, twelve servos

Commands are packets over a shared bus. Every servo hangs off the same cable and is addressed by ID, up to 253 of them. The servo also reports back: position, speed, load, voltage and temperature.

That matters for a robot with twelve joints. One cable instead of twelve, and I can ask a joint where it actually is.

03What I set

SettingRegisterValue
ID513
Angle limits9, 111700 – 3242
Max torque16250 / 1000
Position correction310
Operation mode330 — position

Every servo ships as ID 1, so each joint gets its own address before the next one goes on the bus. The angle limits are the measured mechanical range minus 50 steps at each end, so the leg cannot drive into the frame. Max torque at 25% means a jammed joint stops instead of breaking a printed part. Position correction came set to 85 from someone else's calibration, so I zeroed it.

04Testing it

Five full sweeps across the whole 135.5°:

MeasureResult
Temperature35 → 35 °C
Position error≤ 5 steps (0.44°)
Load3.2% / 4.8%
Drift between cyclesnone

All five cycles gave the same error and the same load, to the step. If anything were binding or working loose, the fifth run would differ from the first.

The error of a few steps is expected — the servo has a dead zone of one step in each direction, so it stops just short of the target rather than hunting for it.

Worth saying: this is an unloaded leg. Once the robot stands on it the load will be much higher, so 4.8% says nothing about whether a 25% torque limit is enough to walk on.
